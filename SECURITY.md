# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability in this project:
1. Please do **not** create a public GitHub issue.
2. Reach out via email or create a private security advisory under the **Security** tab of this repository.
3. Include details of the vulnerability and steps to reproduce.
